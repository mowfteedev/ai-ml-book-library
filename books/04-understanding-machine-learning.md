## 2. Tóm tắt cốt lõi (Executive Summary)

*Understanding Machine Learning* là giáo trình chuẩn mực về lý thuyết học thống kê (Statistical Learning Theory). Cuốn sách cung cấp cơ sở toán học lý giải tại sao và khi nào máy học có thể tổng quát hóa từ dữ liệu (PAC Learning, VC-dimension, No-Free-Lunch theorem), trước khi kết nối lý thuyết vào việc phân tích các thuật toán kinh điển như SVM, Boosting, Random Forests, Neural Networks và Online Learning.

## 3. Cấu trúc nội dung (What's Inside)

| Phần / Chương | Tên chủ đề | Nội dung trọng tâm |
| :-: | :--- | :--- |
| **Part I** | Nền tảng lý thuyết học máy | Khung PAC-learning, ERM, Định lý No-Free-Lunch, Chiều VC (VC-dimension), Đổi bù Bias-Complexity. |
| **Part II** | Từ lý thuyết tới thuật toán | Bộ dự báo tuyến tính, Boosting (AdaBoost), SVM & Kernel Trick, Cây quyết định, Nearest Neighbor, Mạng Neural. |
| **Part III** | Các mô hình học mở rộng | Học trực tuyến (Online Learning), Phân cụm (Clustering), Giảm chiều dữ liệu (PCA), Mô hình sinh (Generative Models). |
| **Part IV** | Lý thuyết học máy nâng cao | Độ phức tạp Rademacher, Số bao phủ (Covering numbers), Tính ổn định (Stability), Tối ưu hóa lồi và SGD. |
